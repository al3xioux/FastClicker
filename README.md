# FastClicker

Clicker chronométré : 5 secondes pour cliquer le plus possible. Projet fil rouge d'une
formation DevOps / Docker / CI-CD, dockerisé étape par étape.

## Lancer le jeu en local

Aucune dépendance, aucun conteneur à ce stade : ouvrir `frontend/index.html` dans le navigateur.

## Structure

```
frontend/   le jeu (html/css/js statiques)
```

## Journal de bord

Les mesures et incidents de chaque étape sont consignés ici au fil de l'eau.

### Étape 1 — Le jeu fonctionne (sans Docker)

- Base HTML/CSS/JS posée : bouton de clic, score et chrono affichés.
- Rien à mesurer à cette étape (pas encore de conteneur).
